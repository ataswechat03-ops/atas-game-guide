# ATAS CMS Phase 2

Included in this phase:

- Step-by-step guide editor with image/video/note fields
- Persistence bridge for provider and step data through the existing API
- Frontend provider filtering
- Frontend rendering for step-by-step guides
- Version snapshot comparison UI

Deferred to backend phase:

- Scheduled publishing
- Multi-user role permissions
- Cross-user analytics dashboard

These deferred items require backend schema/auth changes and are intentionally not implemented as frontend-only controls.
