# ATAS 遊戲培訓中心 V2

V2 與目前 V1 平行存在，V1 正式版不修改。

## 原則

- 保留 Railway API 與現有 SQLite 資料
- 不刪除教學、學員、進度、考試資料
- 前台與後台重新模組化
- 不依賴大量 MutationObserver
- 資料讀取統一由 `js/api.js` 負責
- 前台畫面統一由 `js/app.js` 控制
- 樣式集中於 `css/app.css`
- 後續學員、考試、後台各自獨立成模組

## 第一階段

- V2 首頁
- Railway 公開教學資料讀取
- 分類
- 搜尋
- 教學卡片
- 教學詳情
- API 失敗狀態處理

## 後續階段

1. 學員登入與學習進度
2. 收藏、最近學習、完成狀態
3. 實戰題、錯題本、認證
4. V2 後台內容管理
5. V2 培訓管理
6. 完整驗收後再決定是否取代 V1
